Qui trovi tutti i piani mensili. Per aggiungere un nuovo piano, aggiungi una voce in data/plans.json con i campi id, label, meta, gara, file e imposta current: true sul piano attivo.

Come aggiungere un nuovo piano

  1. Crea il file JSON del piano in data/ (es. plan_lugoset2026.json) con la struttura piani, details, weeks.
  2. Apri data/plans.json e aggiungi una voce con "current": true per il nuovo piano e "current": false per il precedente.
  3. Aggiornare bot/config.py non è necessario: il bot legge il manifest automaticamente.
